# SPCIM-T1 极端毁灭性边界测试报告（Destructive Boundary Test）

| 项 | 值 |
|---|---|
| 场景 A 注入 | 100 Gevent/s（设计 32 Gevent/s） |
| L3 容量 | 23 lane / 705 ps = **32.62 Gevent/s** |
| 过载比 | **3.07×** |
| 场景 B 热容 | C_die=0.0264 J/K, C_plate=243 J/K, C_liquid=8372 J/K |
| 场景 C 时序 | 周期 800 ps, 路径 705 ps, 裕度 95 ps |

## 1. 场景 A：L3 查表器在 100 Gevent/s 下的崩溃

| 节点 | 时刻 | 事件 |
|---|---|---|
| T+0 | 0 | 100 Gevent/s 注入（每事件间隔 10 ps，整数精确） |
| T+121.7 ns | FIFO 满 | 首次丢弃；此时仍以 32.6 Gev/s 服务 |
| T+150.0 ns | 逃逸阶跃 | 弃包比 96% ≫ 1e-3 → 切 25 ns 兜底 |
| T+1.20 µs | **永久锁死** | 1 µs 复检窗内弃包比仍 ≫1e-3 → 无法退出 |

- 稳态吞吐：0.92 Gev/s；丢弃率 99.08%
- 物理原因：容量 = 23 lane / 705 ps = 32.6 Gev/s < 100 Gev/s (3.07x 过载); FIFO 8192 项在 121.6 ns 内填满
- 不可恢复性：25 ns 路径下服务率 = 23/25000 ps = 0.92 Gev/s，而到达 100 Gev/s；逃逸比固定点 99.08% ≫ 1e-3，状态机永不回落 → 只能靠降载或 L4（已禁用）

## 2. 场景 B：FSS 归零 + 液冷断流的热崩溃

| 假定 | 125℃ (CMOS 结温) | 250℃ (IrMn 阻塞温度→数据死) | 450℃ (焊料/互扩散) |
|---|---|---|---|
| B0 基准 (液冷正常) | 永不 | 永不 | 永不 |
| B1 断流 (湿回路) | 265.4 s | 1.89 h | 6.74 h |
| B2 断流 + 干回路 | 109.2 s | 279.5 s | 710.7 s |
| B3 干回路 + 绝热机箱 | 100.6 s | 226.6 s | 428.2 s |
| B4 仅 L1 自发热 + 芯片绝热 | 2.6 s | 5.9 s | 11.2 s |
| B5 250 W 灌入 L1 裸 die (最激进) | 10.6 ms | 23.8 ms | 44.9 ms |

物理顺序：**125℃** = 12 nm FinFET 可靠性上限；**250℃** = IrMn 反铁磁阻塞温度 $T_B$，超过后交换偏置消失、钉扎层变自由层 ⇒ 全部比特的参考态崩塌（不可逆数据死亡）；**400℃** = CoFeB/MgO 互扩散；**450℃** = 焊料/底填胶分解（物理损毁）。

**关键裁决**：L1 自身功耗仅 1 W，芯片级绝热下到 250℃ 需 5.9 s；要得到「几毫秒」必须在最激进假定下（250 W 全灌入 L1 裸 die 的 0.0264 J/K）才成立 = **23.8 ms**。现实系统（液冷断流+干回路）是 3.8 分钟量级。

### 2.1 FSS 归零的电磁失效（比热失效早 8 个数量级）

- 耦合模型：$V_{CM}=E\cdot l_{eff}$，40 GHz 时 $l_{eff}=\lambda/20=375$ µm
- 失效阈值（SE=0）：$E_{crit}=190$ V/m 即可让共模吃掉 71 mV 差分裕度的一半
- 有 30 dB 屏蔽时阈值抬到 $E_{crit}=6.0$ kV/m（31.6×）

| 环境场强 | SE=0 时 V_CM | 判定 | 30 dB 屏蔽后 V_CM | 判定 |
|---|---|---|---|---|
| 实验室/机房 1 V/m | 0.37 mV | OK | 0.012 mV | OK |
| 城市环境 10 V/m | 3.75 mV | OK | 0.119 mV | OK |
| 1 m 处 100 W 发射机 200 V/m | 74.95 mV | **失效** | 2.370 mV | OK |
| HPM 武器 10 kV/m | 3747.41 mV | **失效** | 118.503 mV | **失效** |

**结论**：FSS 归零后，只要环境场强 ≥189 V/m（1 m 处 100 W 发射机量级），读出 BER 在第一个采样窗（1 ps 传感 + 80 ps 累加 = 81 ps）内即跳到 0.5；随后 L3 逃逸率 50% ≫ 1e-3 → 1 µs 内锁死。**电磁死比热死早约 8 个数量级**（100 ps vs 24 ms~2.7 h）。

## 3. 场景 C：10% 抖动 + SEU 下的 TMR 响应

| 注入 | TMR 能否掩蔽 | 容错响应延迟 | 首次失效 |
|---|---|---|---|
| C1 10% 峰峰抖动 (±40 ps) | 不需要掩蔽 (裕度 55 ps > 0) | — | 无 |
| C2 10% RMS 抖动 (sigma=80 ps) | **不可能**: 共源时钟 = 共因失效, 三模同时错且表决一致 | — | 7.2 ns |
| C3 SEU 单副本 (自然通量) | 能 (空间隔离, 表决器 2/3 多数) | 885 ps | 无 |
| C4 SEU 强化注入 (1e-3/副本/周期) | 单副本: 能; 双副本: 不能 (fail-stop) | 885 ps | 48834.4 ns |

- **C1 10% 峰峰抖动 (±40 ps)**：最坏路径 745 ps < 800 ps, 全 400000 周期无违规
- **C2 10% RMS 抖动 (sigma=80 ps)**：P(违规)=0.1245/周期 -> 平均 8.0 周期 = 6.4 ns 首错; 错值三模一致 -> 不告警, 静默错误率 1.56e+08/s
- **C3 SEU 单副本 (自然通量)**：SER=1.46e-09/s/副本 -> 双重命中 MTBF=1.86e+19 年; 响应延迟 885 ps 属潜在能力
- **C4 SEU 强化注入 (1e-3/副本/周期)**：200000 周期: 掩蔽 638 次 (首 161 周期 = 129 ns), 双副本失效 1 次 (首 48834 ns)

**TMR 的本质边界**：三模冗余只能掩蔽**空间隔离**的单粒子翻转（响应延迟 885 ps = 1 周期 800 ps + 表决 85 ps）。对**共源时钟抖动**它是零效的——三模共享同一时钟树，setup 违规同时发生且三路结果一致，表决器输出一个「三模一致地错」的值，不产生失配告警。因此 10% RMS 抖动下 TMR 的容错响应延迟是 **∞（不响应）**，系统在首个违规周期即静默错误，错误率 = P(违规)×1.25 GHz。

### 4.1 三个「绝对时间点」

1. **L3 溢出起点 = T+121.7 ns**：FIFO 8192 项被 100 Gev/s 注入填满。
2. **L3 崩溃点 = T+150.0 ns**：逃逸比 19% ≫ 1e-3，阶跃 25 ns。
3. **L3 永久锁死 = T+1.20 µs**：25 ns 路径服务率 0.92 Gev/s，逃逸比固定点 99.08%，状态机永不回落。

### 4.2 一个反直觉的排序结论

**抖动造成的首个错误决策（T+7.2 ns）比 L3 溢出（T+121.7 ns）早 17 倍，比 L3 永久锁死（T+1.20 µs）早 167 倍。** 也就是说，在 100 Gev/s 场景下，L3 查表器并不是第一个倒下的部件——时钟抖动先把错误决策送进了 GPU。若系统只监控 L3 的逃逸计数器，它会在「数据已经错了、但计数器仍然干净」的窗口里运行，而这个窗口比 L3 锁死时刻还长两个数量级。

### 4.3 L4 即使开启也救不了这条路径

| L4 动作 | 时间尺度 | 对比 L3 锁死 1.20 µs |
|---|---|---|
| 膜层破裂检测 | <1 s | 慢 8.3e5× |
| MEMS 法拉第笼展开 | 45 µs | 慢 37× |
| 换膜 | 30 s | 慢 2.5e7× |

L4 是为**老化/膜层损伤**设计的慢回路（毫秒~秒），而吞吐过载的锁死发生在**微秒**。两者相差 3–7 个数量级，**L4 在架构上无法覆盖过载失效**。唯一有效手段是在 L3 入口加准入控制（令牌桶 + 双水位 FIFO 比较器，响应 1 周期 800 ps），把 100 Gev/s 削峰到≤32 Gev/s；本题中该机制不存在，因此 150 ns 必崩。

## 5. 失效物理原因（逐节点）

| 节点 | 物理原因 |
|---|---|
| 抖动静默错误 | 三模共享同一时钟树，setup 违规是**共因**；表决器比较的是数据不是时序，三路一致地为错 → 失配标志不置位 → 错误不可检测 |
| L3 溢出 | M/D/23 队列：容量 = N_lane/latency = 23/705 ps = 32.62 Gev/s < 100 Gev/s，过载 3.07×；FIFO 深度 8192 只能吸收 121.7 ns 的差额 |
| 25 ns 锁死 | 兜底路径服务率 = 23/25 ns = 0.92 Gev/s；逃逸比固定点 = 1−0.92/100 = 99.08%，永远 >1e-3 → 状态机不存在退出条件（不稳定不动点） |
| FSS=0 读出崩塌 | 共模耦合 V_CM=E·λ/20 达到 V_diff/2 时差分裕度被吃光；30 dB 屏蔽把阈值从 190 V/m 抬到 6.0 kV/m |
| 250℃ 数据死亡 | IrMn 反铁磁阻塞温度 T_B≈250℃，超过后交换偏置消失、钉扎层变自由层，全部比特参考态崩塌（不可逆）。注意：按 Δ(T)=E_b/k_BT 算，保持失效要到 **851℃**，所以热数据死亡的真实判据是 T_B 而非 Arrhenius——这是一个容易被误判的物理点 |
| 450℃ 物理损毁 | 焊料/底填胶分解 + CoFeB/MgO 互扩散（Ea=2.0 eV，I>1） |

## 6. 结论：从降级到宕机的三段区间

- **T+0 ~ T+7.2 ns**：全系统无任何告警，但时钟裕度已被 10% RMS 抖动吃光；首个 setup 违规出现在 7.2 ns，且三模一致地错 ⇒ 不产生失配标志。
- **T+121.7 ns ~ T+1.20 µs**：降级运行——服务率从 32.6 Gev/s 跌到 0.92 Gev/s，丢弃 99.08%。
- **T+1.20 µs 之后**：功能性宕机（不是物理宕机）。系统仍通电、仍散热、MTJ 数据完好，但每秒只能处理 0.92 Gev/s，对 100 Gev/s 的上游等于 100% 丢包。
- **热宕机是另一条独立时间线**：若同时断液冷，数据死亡在 23.8 ms（最激进假定）到 1.89 h（湿回路现实假定）之间；但它比功能性宕机慢 4–10 个数量级，**在时间序上根本不是同一起事故**。

**最终判定**：本题三注入并发下，系统的**实际宕机顺序**是 抖动静默错误(7.2 ns) → L3 溢出(121.7 ns) → L3 锁死(1.20 µs) → 热数据死亡(≥23.8 ms)。L3 不是最脆弱环节，**时钟完整性才是第一道防线**；而 L4 的物理降级回路对这条路径完全无效。
